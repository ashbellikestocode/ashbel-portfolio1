# Ashbel Nixon — Portfolio

A responsive static portfolio built with HTML, CSS, and vanilla JavaScript.

## Files
- `index.html` — portfolio homepage
- `upcoming.html` — separate upcoming projects page
- `style.css` — styles and responsive layouts
- `script.js` — mobile navigation, connected-node canvas, reveal animations, command palette, and custom cursor
- `ashbel.jpg` — portrait image (kept in repository root for easy upload)

## Publish on GitHub Pages
1. Upload all files in this folder to the root of your portfolio repository.
2. Open repository **Settings → Pages**.
3. Select **Deploy from a branch**, choose `main` and `/(root)`, then save.
4. Wait for the Pages deployment to finish.

The education section includes VIT Vellore and Indian School Muscat. The ISM panel is an original illustration for now; replace it with a real campus photo if you have one. The site links directly to the supplied repositories: Friday AI Chatbot, LawLM, and InTheMarket. The Upcoming page features Friday's next iteration, the Railway Ticket Booking System, and the planned Expense Tracker. The expense tracker does not have a repository link yet.

## Customize
Edit text in `index.html` and `upcoming.html`. Replace `ashbel.jpg` in the repository root to change the portrait. Update the email address in both HTML files if it changes.
